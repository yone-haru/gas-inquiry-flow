現在の変更を安全にコミットしてください。ユーザーの意図: $ARGUMENTS

## 現在の状態

!`git status --short`

!`git diff --stat HEAD`

## 手順

1. **検証を先に**: CLAUDE.md の `【test】`・`【lint】` を実行する。落ちたらコミットせず、原因を報告して修正から始める。
2. **秘密情報チェック**: ステージ対象に `.env`・APIキー・認証情報が含まれていないか確認する。含まれていたら除外して警告する。
3. **論理的に分割**: 無関係な変更が混ざっていたら、意味のある単位ごとに複数コミットに分ける。`git add` はファイル単位で行う(`git add -A` を無条件に使わない)。
4. **コミットメッセージ**: 変更の「なぜ」が分かる1行サマリ+必要なら本文。プロジェクトの既存コミットのスタイルに合わせる。
5. **push はしない**(ユーザーが明示的に頼んだ場合のみ)。

コミット後、`git log --oneline -3` で結果を示すこと。
