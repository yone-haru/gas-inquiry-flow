次のタスクを最後まで自律的に完遂してください: **$ARGUMENTS**

CLAUDE.md の「エージェントの動き方」と「検証ループ」を厳守すること。特に: 途中で確認を求めない・エラーで止まらない・証拠なしに成功を主張しない。

## ループ手順

### 1. 計画
- 関連コードを調査し、複数ファイルにまたがる変更なら先に `.claude/plan.md` にプランを書く。
  - 内容: ゴール / 変更するファイル / 手順 / 完了条件(検証方法)
- 仮定が必要なら合理的なベストを選び、plan.md に「仮定:」として1行残す。

### 2. 実装
- plan.md の手順に沿って実装する。論理的な区切りごとに進める。
- スコープ外の大規模リファクタはしない。

### 3. 検証(実装とは分離)
- `verifier` サブエージェント(Agent tool)に検証を依頼する。渡す情報: タスクの内容と完了条件。
- verifier が FAIL を返したら、[must]/[should] の指摘を修正して再度検証に出す。PASS になるまで繰り返す。

### 4. 記録
- 進捗・得た知見・試みて失敗したことを `.claude/loop-result.md` に随時追記する。
- プロジェクト固有の罠を見つけたら、**即座に CLAUDE.md の「ハマりどころ」に追記**する。

### 5. 完了
- 完了条件(CLAUDE.md の停止条件1)を満たしたら、`/commit` の手順に従い論理単位でコミットする。
- 最終報告: やったこと / 検証の証拠(コマンドと結果) / 残課題。

## 停止条件

CLAUDE.md の停止条件に従う。試行上限を超えて前進がない場合のみ、原因と試したことを `.claude/loop-result.md` に書いて停止する。それ以外は止まらない。
